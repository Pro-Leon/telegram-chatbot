## Compatibility & Performance

- **Migrations additive, idempotent**: `20260831000002_creator_isolation.sql` adds nullable `creator_id` columns + partial unique indexes; existing rows remain readable via `OR creator_id IS NULL`; `ON CONFLICT DO NOTHING` handles both.
- **Canonical generation_id unchanged** (`MD5(user:msg:tgId)`) — retry/XAUTOCLAIM/telemetry correlation still deterministic; downstream composite fixes dedup/telemetry.
- **Performance**: Extra `creator_id` filter uses new index `idx_messages_creator_user_created` (same cost as before, indexed); persona snapshot single fetch saves one SELECT per generation (net -1 query); dedup extra key prefix negligible.
